# Florencia Barrera's Workspace

A static HTML workspace for a Dr. Love's 100% Pure Moringa promotional landing page.

## Overview

This project contains responsive marketing pages built with HTML and Tailwind CSS. The main page presents product information, benefits, usage instructions, ingredient details, purchase offers, and calls to action for Dr. Love's Organic Moringa.

## Project structure

- `index.html` — Main landing page.
- `moringa-bi-a.html` — Moringa landing-page variant.
- `moringa-bi-a-v2.html` — Updated Moringa landing-page variant.
- `moringa-bi-b.html` — Additional landing-page variant.
- `moringa-bi-b-2.html` — Additional landing-page variant.
- `css/` — Compiled CSS assets.
- `src/` — Tailwind CSS source files.
- `old-pages/` — Archived or previous page versions.
- `package.json` — Project metadata and CSS build script.
- `SECURITY.md` — Security policy.

## Technologies

- HTML5
- Tailwind CSS 4
- Bootstrap Icons
- Google Fonts (Inter)
- Wistia video embed

## Getting started

### Prerequisites

- Node.js and npm

### Install dependencies

```bash
npm install
```

### Build the CSS

```bash
npm run build:css
```

### Preview locally

Open `index.html` in a browser, or serve the repository with a local static server:

```bash
npx serve .
```

Then visit the local URL shown by the server.

## Notes

The landing pages reference externally hosted images, videos, fonts, icons, and checkout links. An internet connection is therefore required for all content to render correctly.
